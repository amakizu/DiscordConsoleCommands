# Discord Console scripts collection
**Allows you to modify some of unavailable Discord features through browser console**

Desktop: Make sure to open your browser's console tab then allow access to paste something; paste the script there
Mobile (Android): Install Kiwi browser on Play store and ope the console tab, paste the script there


**/!\ IMPORTANT NOTE: THIS MAY BREAK DISCORD'S TOS; USE AT YOUR OWN RISK**


1. [Reset your profile banner color to default](https://github.com/wifcat/DiscordConsoleCommands/blob/main/ResetProfileBannerToDefault.js)
2. [Add or Remove hypesquad](https://gist.github.com/yuuslokrobjakkroval/3d94447c9597a1c19f6b0eba03e5ca08)
